# 리센느 계열사

> 리센느와 함께한 기업 위키

리센느를 후원했거나 후원 중인 기업과, 기업이 공개한 관련 이미지·영상 링크를 팬들이 함께 정리하는 비공식 팬 사이트입니다.

- 사이트: https://seogineer.github.io/rescene-affiliates/
- 기술: [Astro](https://astro.build) + GitHub Pages
- 편집 방법: [CONTRIBUTING.md](CONTRIBUTING.md)

## 개발
```sh
npm install
npm run dev      # http://localhost:4321/rescene-affiliates/
npm run build
```
